Auditory Working Memory (pitch) – patient task

Experimenter screen. Use headphones. Chrome / Edge recommended. Works offline.

MEG study used 52 phon; raise for older patients / ward noise.

Keys during the task — Participant: 1 / ← = SAME, 2 / → = DIFFERENT (or click / touch the big buttons). Experimenter: P = pause after current trial (Space resumes), Esc = stop & save. Data are downloaded automatically as CSV at the end and are also backed up in the browser after every trial.
